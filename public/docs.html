API reference

Every feature in the dashboard is available over a JSON REST API. Phone numbers are accepted in local (0712345678) or international (+254712345678) format and are always returned in E.164.

Authentication

Send your API key with every request in the X-API-Key header. Authorization: Bearer <key> also works.

curl https://your-host/api/account -H "X-API-Key: $VAS_API_KEY"

Errors

Errors return a non-2xx status and a JSON body: {"error": "message"}.

StatusMeaning
400Validation failed, for example an invalid number or a missing message
401Missing or invalid API key
402Insufficient wallet balance
404Resource not found
409Conflict, such as a duplicate keyword or a campaign that cannot be cancelled

Bulk SMS

POST/api/sms/send

Creates a campaign. The cost is debited from your wallet when the campaign is created. Duplicates, invalid numbers and opted-out numbers are removed automatically.

FieldTypeDescription
senderIdstringAn approved sender ID
messagestringUp to 1,530 characters. Supports {name}, {first_name} and {phone}
recipientsstring[] | stringPhone numbers (array, or a comma/space-separated string)
groupIdsstring[]Contact groups to include
scheduleAtISO dateOptional future send time
namestringOptional campaign label
{
  "id": "cmp_3f9a1c2b7d4e",
  "status": "queued",
  "recipients": 2, "invalid": 0, "duplicates": 1, "optedOut": 0,
  "cost": 1.4,
  "stats": { "queued": 2, "sent": 0, "delivered": 0, "failed": 0, "scheduled": 0, "cancelled": 0 }
}
POST/api/sms/estimate

Same body as /send. It returns the encoding (GSM-7 or UCS-2), the segment count, the per-network cost and your balance, without sending anything.

Premium subscriptions

Subscribers opt in by texting a keyword to a shortcode, by choosing a USSD menu item, or through the API. STOP unsubscribes them. Broadcasts are billed to subscribers, not your wallet, and you earn a revenue share on each delivered message.

GET/api/services
POST/api/services
{ "name": "Football Scores", "keyword": "GOAL", "shortcode": "22384", "price": 5 }
GET/api/services/:id/subscribers
POST/api/services/:id/subscribers { "phone" }
POST/api/services/:id/broadcast { "message" }

USSD

GET/api/ussd/apps
POST/api/ussd/apps
PUT/api/ussd/apps/:id

A menu is a tree of nodes. A node with options continues the session (CON). A node without them ends it (END). Callers can press 0 to go back or 00 to return to the main menu.

{
  "name": "Self-care", "serviceCode": "*384*55#",
  "menu": {
    "text": "Welcome",
    "options": [
      { "key": "1", "label": "Balance", "next": { "text": "Your number is {phone}" } },
      { "key": "2", "label": "Join news", "next": {
          "text": "Subscribed!", "action": { "type": "subscribe", "serviceId": "svc_news" } } }
    ]
  }
}
POST/api/ussd/callback no auth

This endpoint is called by the USSD gateway. It accepts JSON or form-encoded sessionId, serviceCode, phoneNumber and text, where text holds all inputs joined with *. It returns plain text that starts with CON or END.

Airtime

POST/api/airtime/send
{ "recipients": [ { "phone": "0712345678", "amount": 100 } ] }

Amounts must be whole numbers from 10 to 10,000. You are charged face value minus the airtime discount, and failed top-ups are refunded automatically.
