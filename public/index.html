How it works

Live in an afternoon

Start sending from the dashboard straight away, or wire up the REST API when you are ready to automate.

Fund your wallet

Top up with M-Pesa, card or bank transfer. You pay only for what you send. There are no monthly fees.

Import your audience

Paste or upload contacts, organise them into groups, and VASlink normalises and de-duplicates every number.

Send & measure

Launch campaigns, USSD menus or airtime payouts, then watch delivery reports arrive in real time.

Built for developers

A clean REST API with JSON in and JSON out. The webhook formats follow the conventions of the main African gateways, so your existing integrations still work.

  • API-key authentication
  • Delivery-report and inbound-SMS callbacks
  • USSD callback with CON / END responses
  • Pluggable gateway: simulator or Africa's Talking

# Send a personalised bulk SMS
curl -X POST https://your-host/api/sms/send \
  -H "X-API-Key: $VAS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "senderId": "VAS_DEMO",
    "message": "Hi {name}, your order has shipped!",
    "recipients": ["0712345678", "0733456789"],
    "groupIds": ["grp_customers"]
  }'
const res = await fetch('https://your-host/api/sms/send', {
  method: 'POST',
  headers: {
    'X-API-Key': process.env.VAS_API_KEY,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    senderId: 'VAS_DEMO',
    message: 'Hi {name}, your order has shipped!',
    recipients: ['0712345678'],
  }),
});
const campaign = await res.json();
console.log(campaign.id, campaign.cost); // cmp_… 0.8
import os, requests

r = requests.post(
    "https://your-host/api/airtime/send",
    headers={"X-API-Key": os.environ["VAS_API_KEY"]},
    json={"recipients": [
        {"phone": "0712345678", "amount": 50},
    ]},
)
print(r.json()["total"])  # 48.5, i.e. 3% discount
